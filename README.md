# Github ARPG

横版挂机刷宝游戏原型。当前版本聚焦验证核心循环：自动战斗、怪物击杀、掉落生成、装备替换、分解材料、离线收益和简单关卡推进。

## Run

```bash
npm install
npm run dev
```

## Prototype Notes

- 技术栈：Vite + React + TypeScript。
- 战斗：每 0.9 秒自动结算一次伤害，击杀后刷新怪物。
- 成长：经验提升英雄等级，装备提供战力、攻速和寻宝值。
- 掉落：装备有武器、护甲、护符三种槽位，以及灰装、魔法、稀有、史诗、传说五种稀有度。
- 经济：分解装备获得裂片，裂片可释放过载斩击。
- 存档：使用 `localStorage` 保存，并计算最多 4 小时离线收益。
