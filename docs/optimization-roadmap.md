# 玩法优化路线图

日期：2026-05-31
依据：玩家反馈 7 项 ＋ 当前系统现状

---

## 一、玩家反馈翻译为可执行命题

| # | 玩家原话 | 翻译为可执行问题 |
|---|---|---|
| 1 | 刷怪要爽，命中/击杀有反馈，伤害大但有层次 | 战斗反馈层（震屏/闪光/数字弹性/击杀反馈差异化） |
| 2 | 掉率有稀有度分级，有稀有物品 | item rarity tier 视觉化、稀有度区分 |
| 3 | Build 之间要有明显不同 | 技能/天赋分支需要"风格化"而非"数值化" |
| 4 | 传说装备应该改变规则 | 现有 legendaryPowers 只是数值加成，需要"改规则"型词条 |
| 5 | 每阶段要有目标 | 短/中/长期目标系统（任务、解锁、成就） |
| 6 | 怪物难度不堆血量，要测试 build | 怪物机制化（抗性/弱点/AI 模式） |
| 7 | 重复刷怪要藏随机性 | 词缀池随机/套装随机/事件随机 |

## 二、当前系统现状（基线）

### 已具备
- 战斗循环：tick + skill cooldown + AOE + 群战
- 装备：8+ 词缀池，rarity 已建模（normal/magic/rare/legendary）
- 技能：cleave / lacerating_sweep / execute / iron_oath（4 个）
- 传说：3 件 legendaryPowers（onCriticalStrike 强化等）
- 区域：5 act × 10 zones（设计文档完成，落地 zone 数量待查）
- 4 职业可选（动作资源已接入）
- 数值层：armor / DR / crit / bleed / execute threshold

### 关键缺口
- **战斗反馈薄**：crit 只有数字闪烁，没有震屏 / hitstop / 弹性数字 / VFX
- **稀有度无视觉**：物品 tier 在 UI 上颜色弱，掉落不显眼
- **Build 同质化**：4 技能数值都是"加伤害"，没有"改规则"
- **传说装备只是数值**：no "斩杀阈值变 20%"、"基础斩多段化"等改规则词条
- **目标驱动不足**：只有等级和章节，无短期目标 hook
- **怪物千篇一律**：所有敌人都是站桩输出 + 血量缩放，没有抗性/弱点/特殊机制
- **随机性集中在词缀**：套装/词条池/事件随机性少

## 三、P0 — 立刻能做、收益最大（本周）

### P0-1 击杀反馈层（解 #1）
**问题**：击杀只是数字飘+log 行，缺爽点。
**做什么**：
- hitstop：crit/execute 命中时整个 stage 冻结 30-60ms（`document.body.style.animationPlayState`）
- 震屏：hit / crit / execute 不同强度的 transform shake（已有 `shake-crit/shake-hit` 类，扩参）
- 数字弹性：浮动文字按 `kind` 分等级（普通/暴击/处决/格挡），字号、颜色、出场动画差异化
- 击杀反馈：敌人死亡时屏幕中心一个短暂闪光 vfx（粒子向外）+ 0.1s 慢动作

**估时**：1 天，纯前端，零数值改动
**验证**：录屏对比 / Playwright 截图序列

### P0-2 物品稀有度视觉分级（解 #2）
**问题**：`rarityMeta` 已有，但 UI 上 normal/magic/rare/legendary 区分弱。
**做什么**：
- 物品边框颜色：normal=灰、magic=蓝、rare=黄、legendary=橙、unique=红（参考 D3）
- 高稀有度掉落时屏幕额外效果：rare 出现金光柱、legendary 出现红色光柱 + 短文字提示
- 物品弹出时按 rarity 触发不同打印动画（普通滑入、稀有放大旋转）

**估时**：0.5 天
**验证**：刷一波怪眼测，看到 magic/rare 是否一眼可识别

### P0-3 传说装备 3 件改为"改规则"型（解 #4）
**问题**：现有 3 件 legendary 都是 `onCriticalStrike +X` 类数值加成。
**做什么**：选择 3 件最热门效果改造，例如：
- "灼烬之誓"：基础斩 cleave 变成"挥砍 3 次，每次伤害递减 30%"
- "永不安息"：处决阈值从 20% → 35%，但处决冷却 +50%
- "锈蚀血盟"：暴击不冷却基础斩，但失去全部基础暴击伤害

**实现方式**：
- engine 端 hook：onCleaveExecute、onCriticalStrike、onExecuteCheck（已部分存在）
- 改造的不是数字，而是 skill 流程函数

**估时**：1.5 天
**验证**：装备前后行为肉眼明显不同；reducer test 加 3 个 case

### P0-4 短期目标条（解 #5）
**问题**：玩家上线没有 5 分钟内的小目标驱动。
**做什么**：左上角"今日 3 任务"小条：
- "击杀 30 个敌人"
- "拾取 1 件 rare+ 装备"
- "进入 act 2 第一个 zone"
完成给少量金币/碎片奖励。每日 reset。

**估时**：1 天
**验证**：UI 出现，刷怪能看到进度条更新

## 四、P1 — 中等收益、本周或下周（架构准备）

### P1-1 怪物机制化（解 #6）
**问题**：所有敌人 AI 一致。
**做什么**：定义 `enemyTrait` 字段，每只敌人挂 0-2 条机制：
- `armored`：物理减伤 80%，但流血伤害 +200%（针对流血 build）
- `swift`：仇恨距离触发后冲撞两次（针对 turret build）
- `enrage`：血 <30% 攻速 +100%
- `caster`：远程 + 后退（针对纯近战 build）
- `summoner`：每 8s 召唤 2 个小怪
- `reflect`：暴击伤害反弹 30%（针对 crit build）

每 zone 怪物组合 trait 不同 → build 测试自然出现。

**估时**：3-4 天（数值平衡 + AI 状态机）
**验证**：纯 crit build 打 reflect 怪明显吃力，需要换 build

### P1-2 技能分支：每个技能 3 个 rune（解 #3）
**问题**：cleave 永远是 cleave，没分支。
**做什么**：每技能 3 个 rune，玩家 lvl 高了才解锁选 1：
- cleave default
- rune A：变旋风斩（持续 1.5s，半径 +50%，伤害 -20% per tick）
- rune B：变跳斩（向前突进 200px，落地 AOE）
- rune C：变冲锋斩（0 cd 但每次需要 5 stack 蓄力）

每个 rune 改的是技能函数，不是数值。

**估时**：5-7 天（4 技能 × 3 rune = 12 函数 + UI）
**验证**：换 rune 战斗节奏明显不同

### P1-3 套装系统骨架（解 #7）
**问题**：纯随机词缀，缺方向感。
**做什么**：定义 5 套套装（2/4/6 件套效果），词缀掉落概率不变，但带 setId 标签：
- 流血王套（4 件套：流血 +100%；6 件套：流血伤害可暴击）
- 处决套（4 件套：处决阈值 +5%；6 件套：处决重置 cd）
- 召唤套（4 件套：每 5s 召唤一个鬼魂）
- 闪避套（4 件套：闪避 +25%；6 件套：闪避后 1s 攻速 +200%）
- 元素套（4 件套：火/冰/电三选一加 30%）

**估时**：3 天（schema + 5 套 × 数据 + UI 显示）
**验证**：玩家有"凑齐这 4 件"的中期目标

### P1-4 词缀池分层（解 #2 + #7）
**问题**：所有词缀同一池子里随机。
**做什么**：词缀按 tier 1-5 分层（D3 那种），高等级敌人/zone 才掉 tier 5 词缀。每件物品的词缀同一池但 tier roll 独立。
- tier 显示在物品 tooltip：例如 "+45 力量 (T3)"
- 这给"刷指定词缀"带来 hook：玩家会专门去某个 zone 刷 T5 词缀

**估时**：2 天
**验证**：物品 tooltip 显示 T1-T5；高 zone 掉 T5 概率提升

## 五、P2 — 大投入、长期（下个月）

### P2-1 难度阶梯（解 #5 + #6）
- 通关一周目后开放 NM 模式，怪物 trait 数 +1，掉落 tier 提升
- Greater Rift 式无尽难度

### P2-2 词条事件 / 随机区域（解 #7）
- 每 zone 有 10% 几率刷出"赤潮事件"：怪物词缀 +狂暴 +冰冻，掉落额外宝箱
- 进 zone 时 roll 一次环境 buff/debuff（火元素伤害 +50%，物理 -30% 之类）

### P2-3 长期目标：传说图鉴 / 成就（解 #5）
- 传说装备图鉴（已收集 / 未收集），未拥有的显示在哪个 zone 掉
- 成就：1000 击杀解锁皮肤、首次 act 5 通关解锁标题

### P2-4 Build planner UI（解 #3）
- 在背包旁加"流派板"：选定流派后，UI 标记缺哪几件、哪个词缀达不到要求
- 新人不再迷茫"我现在是什么 build"

## 六、本周排序建议

按 ROI（玩家感知改进 / 投入工作量）：

```
本周一-二：P0-1 击杀反馈层 + P0-2 稀有度视觉
本周三-四：P0-3 传说改规则 3 件
本周五  ：P0-4 短期任务条
（P0 完成 → 玩家立即能感觉到游戏"变得有爽点 + 有目标"）

下周一-三：P1-2 技能 rune 分支（先做 cleave 1 个技能 ×3 rune 验证可行）
下周四-五：P1-1 怪物 trait 机制（先做 5 个 trait 接入 5 个怪）
```

P1-3 套装、P1-4 词缀分层放第三周，P2 进入下个月迭代周期。

## 七、需要做的决策（写代码前）

1. **传说改规则的 3 件具体哪 3 件？** 我给的 cleave/execute/crit 三选是基于现有技能，要不要换其他主题？
2. **rune 系统的 UI 怎么放？** 直接在技能图标右键弹出选 rune？还是单独 talent 树？
3. **怪物 trait 的视觉提示是什么？** trait 名字飘头顶？还是怪物身上发对应颜色光？玩家不能不知道"这怪反弹暴击"。
4. **套装是否参与现有词缀掉落？** 还是独立"set drop"通道？前者数据简单，后者更聚焦。

每个决策都会影响接下来 1-2 天的代码方向，建议在动手 P0-1 之前先把这 4 个问题敲定。
